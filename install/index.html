Install NNModelling

NNModelling is a visual editor and DSL for designing neural networks, compiled to PyTorch/Lightning training pipelines. This page installs the repository and starts the editor together with a local training backend — the editor is served from your own machine, not from this site.

One command

From the repository root, after cloning:

$ cd NNModelling && PYTHONPATH=converted/src uv run --project converted python -m backend.cli

This serves the built editor at http://127.0.0.1:8000 and starts the existing training backend on the same origin. Open the URL, pair the Training Sidebar with the default http://127.0.0.1:8000 URL, and train locally.

Prerequisites

  • Git — to clone the repository.
  • Python 3.12+ and uv — the companion runs on uv; the environment is created automatically.
  • Valkey 8 — the backend stores sessions, jobs, and events in Valkey. Start it with just --justfile converted/backend/justfile valkey or the bundled Docker deployment.
  • Node.js and pnpm — only to build the editor once: pnpm install && pnpm --dir front-end build. A built front-end/dist is required; the command fails with build instructions instead of serving an empty UI.
The companion never proxies or routes remote jobs. The Training Sidebar keeps its current URL and pairing workflow, so you may equally connect it to an independently managed remote backend instead of the localhost one.
